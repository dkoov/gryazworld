Как зайти на сервер

После покупки проходки ваш ник автоматически добавляется в белый список. Адрес сервера указан на странице Статистика. Подключайтесь через Java Edition.

Первые шаги

  • Отойдите от спавна — ресурсы там уже истощены
  • Найдите место для базы подальше от других игроков
  • Зайдите в Discord сервера — там можно найти соседей
  • Познакомьтесь с другими и, возможно, вступите в общину

Версия

Сервер работает на Java Edition последней стабильной версии. Пиратская версия поддерживается.

Правила

Правила сервера

Обязательно прочитайте перед игрой.

Основные правила

  • Запрещён грифинг построек других игроков
  • Запрещено воровство из сундуков
  • Запрещены читы, x-ray и другие нечестные модификации
  • Запрещено использование багов и дюпов (кроме разрешённых)
  • Уважительное отношение к другим игрокам обязательно

Санкции

За нарушение — предупреждение, затем временный бан, затем постоянный без возврата средств.

Как подключить карту

Инструкция по установке Dynmap на Minecraft-сервер.

Шаг 1
Скачайте плагин Dynmap на dev.bukkit.org/projects/dynmap
Шаг 2
Положите .jar файл в папку /plugins вашего сервера
Шаг 3
Откройте порт 8123 и перезапустите Minecraft-сервер
Шаг 4
В коде сайта замените блок карты на:
<iframe src="http://ВАШ_IP:8123"></iframe>
