## Плагины по серверам

### Velocity (прокси)

| Плагин          | Назначение                        |
|-----------------|-----------------------------------|
| SimpleProxyChat | Общий чат между серверами         |
| TAB             | Таблица игроков + заголовок/футер |
| LuckPerms       | Права (sync через Redis/БД)       |

### gamegraz + farmserv (общие)

| Плагин         | Назначение                              |
|----------------|-----------------------------------------|
| LuckPerms      | Система прав и групп                    |
| CoreProtect    | Логирование блоков, откат гриферства    |
| FancyHolograms | Декоративные голограммы                 |
| NametagHider   | Скрытие ников за блоками                |
| GSit           | Сидеть / лежать / ползать               |

### gamegraz (только основной)

| Плагин          | Назначение                       |
|-----------------|----------------------------------|
| BreweryX        | Крафт алкоголя и зелий           |
| WanderingTrades | Кастомные товары у торговца      |

---

## Конфиги

Все шаблоны конфигов хранятся в `plugins/configs/<ПлагинName>/`.  
Актуальные конфиги **деплоятся на ВПС** согласно `docs/DEPLOY.md`.
