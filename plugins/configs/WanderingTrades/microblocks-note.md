# WanderingTrades — настройка цены мини-блоков

После установки плагина на сервер:

1. Открыть `plugins/WanderingTrades/trades/microblocks.yml`
2. Заменить `currency: EMERALD` → `currency: DIAMOND`
3. Заменить `price: 1` → `price: 8`
4. `/wt reload`

**Итог:** декоративные головы продаются за 8 алмазов у странствующего торговца.
