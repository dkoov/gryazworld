# WanderingTrades — заметки по микроблокам

Плагин позволяет странствующему торговцу предлагать кастомные предметы.

## Микроблоки

Для сервера GryazWorld через WanderingTrades планируется добавить **декоративные микроблоки**:

- Полублоки из нестандартных материалов
- Декор-предметы (мебель, детали интерьера)
