# CoreProtect

Плагин логирования и отката блоков.

- Устанавливается на **gamegraz** и **farmserv**
- Конфиг по умолчанию подходит для старта
- БД: SQLite (локально в папке плагина)

## Основные команды

```
/co inspect   — режим инспектора (клик по блоку)
/co rollback u:<ник> t:<время>   — откат действий игрока
/co restore u:<ник> t:<время>    — восстановить откаченное
/co purge t:30d                  — очистить логи старше 30 дней
```
