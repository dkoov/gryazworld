# FancyHolograms

Плагин для создания голограмм с поддержкой дисплей-сущностей (1.19.4+).

- Устанавливается на **gamegraz** и **farmserv**
- Требует: Paper 1.21.1, FancyPlugins-API

## Создание голограммы

```
/hologram create <имя>
/hologram edit <имя> addline <текст>
/hologram edit <имя> setline <номер> <текст>
/hologram teleport <имя>
```

## Поддерживаемые анимации

- RAINBOW, WAVE, SCROLL
- Поддержка MiniMessage-форматирования (`<gradient>`, `<rainbow>`, и т.д.)
